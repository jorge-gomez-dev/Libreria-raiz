Librería Independiente Raíz 📚

Historias que conectan con nuestras raíces.

Descripción del proyecto

Librería Independiente Raíz es un sitio web estático diseñado para presentar una librería independiente, destacar su identidad y acercar a los lectores a diferentes propuestas literarias. El proyecto utiliza HTML y CSS, con una estructura sencilla y adaptable a futuras mejoras.

Objetivos

- Presentar la identidad y filosofía de la librería.
- Mostrar recomendaciones y contenido literario.
- Ofrecer una navegación clara para los visitantes.
- Publicar el sitio web mediante GitHub Pages.

Tecnologías utilizadas

- HTML5: estructura y contenido de la página.
- CSS3: estilos, colores y presentación visual.
- Git y GitHub: control de versiones y alojamiento del código.
- GitHub Pages: publicación del sitio web estático.

Publicación del sitio

El sitio está publicado mediante GitHub Pages.

URL pública: https://jorge-gomez-dev.github.io/Libreria-raiz/

Para consultar la página, abre el enlace anterior desde un navegador.

Cómo ejecutar el proyecto localmente

1. Descarga o clona este repositorio.
2. Conserva la estructura de carpetas y archivos.
3. Abre "index.html" en un navegador web.
4. Comprueba que la hoja de estilos "css/estilos.css" se cargue correctamente.

Mantenimiento y mejoras

El proyecto puede ampliarse con nuevas recomendaciones literarias, imágenes de portadas, información de contacto y mejoras de accesibilidad y adaptación a dispositivos móviles.
